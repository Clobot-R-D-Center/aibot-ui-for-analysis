# CLAUDE.md

## Design Context

This app has design context for agents doing UI work:

- **[PRODUCT.md](./PRODUCT.md)** — strategic: register (product), users (external
  customers analyzing their AI service robots), purpose (map + robot visualization
  and spatial/quantitative analysis dashboard), brand personality, anti-references,
  and design principles.
- **[DESIGN.md](./DESIGN.md)** — visual (currently a `<!-- SEED -->`): North Star
  "The Instrument, Not the Cockpit", restrained cool-neutral palette with data-owned
  color, single-sans + mono-numerals type, dual light/dark canvas, WCAG AA +
  colorblind-safe. Re-run `/impeccable document` once real UI exists to capture tokens.

**Core principles:** map is the hero · legible to non-engineers · calm under density ·
honest (colorblind-safe, never color-only) encodings · motion serves comprehension.

Read both before designing or changing UI. Use `/impeccable <command>` for design work.
